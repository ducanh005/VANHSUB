# VANHSUB

Ứng dụng desktop chuyển giọng nói thành phụ đề, dịch và lồng tiếng, tối ưu cho nội dung tiếng Việt.

## Công nghệ

- Electron
- Next.js + React
- Nextron
- TypeScript

## Phát triển

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
